主題說明與 SDGs 目標

雙低家庭兒童關懷

關注 6-12 歲（國小生）關鍵成長期。雙低家庭（低收入、低資源）兒童常因家庭支持與資源不足，缺乏情緒表達管道與正向引導。

核心願景

透過心情筆記 App，打造溫暖無憂的成長環境。

問題分析

家庭支持不足

影響情感正常發展，缺乏日常陪伴。

缺乏情緒素養

缺乏正確情緒管理與心理健康認知。

過度依賴網路

沉迷網路世界，缺乏正向成人引導。

關懷資源有限

現有關懷資源不足，難以及早介入協助。

缺乏安全平台

缺乏一個專屬且安全的心情表達出口。

IT方案架構與介面互動展示

系統技術架構

前端開發

採用 Flutter 跨平台框架與 JavaScript 開發，支援手機、平板及 Web 端存取。

後端與資料庫

使用 Firebase Authentication / Supabase Auth 管理帳號，Firestore 儲存日記與紀錄。

安全與通知

密碼經 Bcrypt 加密，憑證採用 JWT，並整合 Firebase Cloud Messaging 推播。

方案推動與合作利益

學校與親職團體合作

我方獲益

獲取兒童數據樣本、提升品牌信任度與專案口碑。

他方（學校）獲益

社工合作效益

擴展影響年齡層、提供正面聲音，共同連結家庭情感。

衛福部心理健康司/國教署

政策與公信力

提升專案公信力、擴大資源導入。協助公部門推動相關政策與強化服務。

成果發表與宣傳

舉辦發表會與媒體宣傳活動，大幅提升能見度與社會關注度。

06

檢討與反思

產品功能與體驗優化

  • 增添遊戲機制：針對兒童端缺乏吸引力問題，加入趣味互動與獎勵機制。
  • 家長教育專區：設計家長專屬版面，分享教育經驗與正向溝通技巧。
  • 建立求助管道：增設兒童直接聯繫輔導員與社工的功能，確保即時協助。

隱私保護與服務對象擴展

  • 平衡隱私與監控：增設詢問孩子意願之通知設定，避免孩子覺得隱私受侵犯。
  • 多平台適應與對象：擴充不同載具模式，服務對象精準聚焦於國小至國中階段。
  • 社工介面與審核：改善社工端介面，註冊流程增加證明文件與人工審核機制。
